
# Dental Clinic KPI System

A web-based application for dental clinic staff performance evaluation and patient feedback.

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- PostgreSQL
- Prisma ORM

## Architecture
Modular Monolith

## Development Approach
Frontend-first development using typed mock data.

## Project Status
Initial development.
